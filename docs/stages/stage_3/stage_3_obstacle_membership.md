## Спецификация

Цель: геометрическая проверка помех независимо от семантического класса; проверить возможность расширения опор до контрольных объектов. Этап 3, development-проверка этапа 4. Обязательный результат baseline: кандидат + ближайшее расстояние + diagnostics, не классификация людей.

Режим patch/validation. Основной исполнитель, затем safety-review, затем validation — отдельные проходы текущего агента. Цель L1. Среда локальный Node; ROS2 Humble/Ubuntu 22.04/Docker — целевая среда, её новая проверка не заявляется.

Вход: неизменённые XYZ 201 кадров doubleT_obstacle, рабочий source frame lidar_livox, оси и метры остаются demo-допущениями. Transform identity (source <- source); bag/header часы не смешивать. Нет accumulation, background или semantic classifier.

Источники: docs/README_methodology.md, docs/README_work_plan.md, config/geometry_contract.yaml, текущие AutoRails/ReviewGeometry/ObjectCandidates. Старые пути methodology.md/work_plan.md из маршрутизатора отсутствуют; используются существующие README-варианты. Annotations только в evaluator.

Allowed: ReviewGeometry/component assessment, UI описания групп, отдельные тесты и replay coverage evaluator, данный отчёт. Avoid: raw/manifest, активные rail/profile/margin/clustering config, архивные результаты. Прямое продолжение оси и изменение порогов без доказательств не публиковать.

Acceptance: positive intersection не теряется при частичной наблюдаемости; UNKNOWN/обрезка никогда не становятся «помех нет»; расстояние до реальной пересекающей точки, не ближайшей посторонней точки группы; один низкий возврат учитывается прежней веткой; точные source indices, неизменные raw. Синтетика + контрольные кадры и все 201 кадров. Stop: отсутствие дальней пары рельсов не заменять произвольной экстраполяцией.

## Предварительный эксперимент

Read-only Node вызовы AutoRails с forwardMin=0 и stationLength=2/4/6/8, остальные параметры неизменны. На кадре 55 диапазоны 3–39 / 2–30 / 9–45 / UNKNOWN; на 160: 3–35 / 2–38 / 9–45 / UNKNOWN. Эти варианты не принимаются в активную конфигурацию: расширение до 56 м не доказано, на 8 м сечениях нет согласованной пары. Минимум сечений и maxGap при этом не ослаблялись.

## Реализация

В ReviewGeometry добавлен assessComponent: отдельные статусы CORE_INTERSECTION, MARGIN_INTERSECTION, UNKNOWN и OBSERVED_RETURNS_OUTSIDE. Последний относится только к наблюдаемым точкам группы, не означает свободный путь. Положительное пересечение сохраняется при частичной неизвестности; возможная обрезка запрещает отрицательный вывод о полном объекте. Для габарита и отступов сохраняются отдельные ближайшие фактические возвраты. Поля доступны в экспорте кадра; UI показывает русское объяснение и цвет рамки по пересечению, а не тип предмета. Низкие возвраты прежней полной ветки не фильтруются.

Новые файлы tests/test_obstacle_membership.cjs и tests/replay_obstacle_membership.cjs. Последний читает reference-профиль из manifest, использует исходные active configs, явно сохраняет default margins, проводит matching annotations только после детектора.

## Safety-review, отдельный проход текущего агента

PASS_WITH_RISKS для диагностики наблюдаемых пересечений. Оси, пороги, отступы, raw и поддержанный участок не изменены. Невалидные индексы/XYZ, отсутствующий габарит и обрезанная отрицательная группа возвращают UNKNOWN. Положительное одиночное низкое пересечение не подавляется. Измерение расстояния не подменяется ближайшей точкой вне нужной зоны. Ни один статус не разрешает safety decision. Независимый внешний review не выполнялся.
