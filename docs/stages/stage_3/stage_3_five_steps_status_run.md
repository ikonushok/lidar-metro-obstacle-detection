## Уровень и следующий шаг

Отдельный validation-проход текущего агента: **L1 для указанного replay и успешных узких тестов**, L0 для прочитанной интеграции. Полный выбранный набор тестов имеет известное падение; общей готовности не заявляется. Код, конфиги и тесты не изменялись. Добавлены только этот отчёт, план и новый replay-артефакт.

Осталось непроверенным: фактическая калибровка и вынос кузова на повороте, размеченное низкое препятствие на реальной записи, полный поворот, FP/FN, независимый проезд, живой браузер, сквозной ROS2, длинный поток и финальная упаковка.

Следующий минимальный шаг — закончить шаг 4: короткая демонстрация текущей цепочки на движущейся записи с выделением пересечений, расстоянием и потерей опоры. Для низкого препятствия при отсутствии реального размеченного события использовать явно обозначенный synthetic test; затем шаг 5 — разметка и измерение качества. Повторная реализация CurveRailAxis или габарита не нужна. Остаточный риск — слабая/неверная опора, ASSUMED профиль, попадание инфраструктуры; изменение порогов заранее не обосновано.
