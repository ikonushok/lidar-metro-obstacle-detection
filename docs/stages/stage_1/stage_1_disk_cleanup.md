## Спецификация

- Цель: освободить место, удаляя только подтверждённые дубликаты и кэш Python.
- Категория: обслуживание локального окружения, этап 1; режим inspect → cleanup.
- Основание: запрос пользователя; инвентаризация файлов и свободного места.
- Фактическая среда: Windows / PowerShell; Docker используется только для чтения состояния.
- Начальное свободное место C: 16 495 972 352 байта (15,36 ГиБ).
- Объём проекта: dataset 131,46 ГиБ; artefacts 1,93 ГиБ; .venv 0,27 ГиБ.
- Допустимые изменения: удалить dataset/raw/*.zst только после полного побайтового сравнения распакованного потока с соответствующим существующим TAR; удалить неотслеживаемые __pycache__ внутри проекта.
- Не затрагивать: исходники, пользовательские изменения Git, SQLite/bag, несжатые TAR, окружение .venv кроме bytecode, рабочие каталоги плеера, актуальные артефакты этапа 4, работающие контейнеры и Docker-том nodeodm_data.
- Контракты геометрии, времени, ROS2 и требований не меняются. Входные frames, TF, метрики детекции неприменимы.
- Основной агент: текущий агент. Safety-review не требуется; отдельный проход validation выполняет тот же агент.
- Проверка: полное потоковое сравнение, SHA-256 несжатого содержимого, проверка границ путей и отсутствия reparse points, повторное измерение диска и git status.
- Acceptance: удалены только проверенные дубликаты и неотслеживаемый bytecode; используемые данные сохранены.
- Stop conditions: несовпадение потока, ошибка распаковки/чтения, неоднозначный путь, отслеживаемый файл или reparse point.
- Целевой уровень: L1 для узкой операции очистки; никаких новых утверждений о LiDAR runtime.
- Evidence и технический журнал: artefacts/cleanup_2026_09_20/.
