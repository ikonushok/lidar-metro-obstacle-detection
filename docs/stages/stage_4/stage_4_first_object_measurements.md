Расстояние — до ближайшего возврата группы от начала frame датчика. Два совпадения — проверка контрольных точек, не независимый recall 100%. Все остальные кандидаты сохранены и показаны; отсутствие для них разметки не означает ложную тревогу. Номера групп не являются track ID.

Validation отдельным проходом текущего агента: PASS_WITH_RISKS, L1; команды и 29 успешных тестов перечислены в отчёте stage_3_object_candidates.md. Не проверены независимые проезды, интервалы видимости людей, отрицательные интервалы, ROS2 runtime новой ветки и обнаружение на 200 м.

Следующий минимальный тест: размечать интервалы двух людей и проверенные посторонние группы на этом проезде; затем измерить пропуски и ложные тревоги с явно согласованным matching. Не менять пороги под две точки. После этого — независимый проезд и контейнерная интеграция. Остаточный риск: геометрические группы могут быть инфраструктурой, часть объектов обрезается фиксированной полосой; путь вне текущих опор рельсов остаётся UNKNOWN.
