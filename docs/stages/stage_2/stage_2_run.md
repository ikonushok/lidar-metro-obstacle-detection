## Назначение

Браузерный плеер полностью декодирует `doubleT_obstacle` в локальный формат кадров и показывает полный текущий набор finite, non-zero XYZ returns без искусственного прореживания. Есть запуск/пауза, покадровый шаг, перемотка, скорость и ракурсы. Красный wireframe — только справочный контур 2,8 × 3,7 м по явно неподтверждённому визуальному допущению. Плеер не выполняет детекцию препятствий и не вводит геометрическую калибровку.

## Запуск

Из корня репозитория, после извлечения bag этапом 1:

```powershell
./scripts/run_stage_2_player.ps1
```

Скрипт собирает `lidar-mosmetro3d:stage_2-player`, читает `dataset/extracted/doubleT_obstacle` только для чтения, при первом запуске создаёт локальные кадры в `artefacts/stage_2/player`, поднимает server на `http://localhost:8080` и сам открывает страницу в браузере по умолчанию. `Ctrl+C` останавливает server. Повторный запуск использует созданные кадры; `-RebuildData` создаёт их заново. Параметр `-NoBrowser` отключает автоматическое открытие.

Подробная инструкция и ручная проверка осей — в [отчёте плеера](stage_2_interactive_player_result.md). Старый MP4 — исторический артефакт и не является достоверным способом ручного просмотра: он не заменяет этот плеер.

Контур использует только визуальное допущение из `config/geometry_contract.yaml`: движение вперёд — отрицательное направление Y, X — поперечная, Z — вертикальная координаты; начало source frame условно совпадает с осью пути и уровнем рельса; показана длина 0–40 условных метров. Это основано на наблюдаемой дальней протяжённости вдоль -Y, но не доказано калибровкой. Подпись `UNCONFIRMED / manual review only` означает, что эти условия не разрешают `CLEAR`, оценку препятствия или геометрическое расстояние.

## Формат результата

Подготовщик записывает `manifest.json` с числом кадров, topic, числом записей и явным `decimation: NONE`. Каждый `.xyzf` содержит float32 XYZ текущего кадра в source order. `(0,0,0)` no-return и non-finite не рисуются, но их счётчики сохранены и видны в интерфейсе.

## Ограничения

В ТЗ указана задача и среда запуска, но отсутствуют значения осей, единиц, extrinsics, профиля поезда, пути и safety margin. В bag отсутствуют TF, одометрия, карта и разметка событий. Следовательно, нельзя подтвердить рабочий frame, габарит или расстояние до препятствия; для геометрического решения допускается только `UNKNOWN`.

Будущие подтверждённые значения хранятся в [`config/geometry_contract.yaml`](../../../config/geometry_contract.yaml). В текущем виде YAML намеренно выключает геометрическое решение.
