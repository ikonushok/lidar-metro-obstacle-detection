## Завершение

- Изменены два согласованных runtime-файла и прежнее test-ожидание сброса crop. Теперь preference сохраняется, но ось/результат пересчитываются для каждого кадра; при UNKNOWN отображается full raw.
- Ожидание fetch не очищает сцену. Loading/error находятся поверх canvas; его размер не зависит от этих сообщений. Динамическим status-блокам выделена постоянная высота с прокруткой.
- Точная команда воспроизводителя после исправления: exit 0, 3/3. Полный связанный Node-набор: exit 0, 26/26. Повторный прогон также 26/26.
- `scripts/run_stage_2_player.ps1 -NoBrowser`: первый запуск внутри sandbox не смог прочитать Docker config; повтор с разрешением завершился exit 0, существующий сервер переиспользован, Docker build не запускался. Переопубликованы UI assets, XYZ/manifest не пересобраны.
- Browser smoke: http://localhost:8080/?v=playback-fix-1, crop включён, playback 0 -> 111; preference true на наблюдаемых 1/39/111; scene x=0,y=587,width=1265,height=200 на всех трёх замерах с открытыми инструментами. На screenshot виден предыдущий кадр во время загрузки, без пустой сцены. Это выборочные проверки, не непрерывный FPS benchmark.
- Пользовательская исправленная вкладка оставлена на кадре 0, crop включён, инструменты свёрнуты, воспроизведение остановлено. Прежние вкладки не перезагружались: возможные несохранённые отметки не потеряны.
- Safety-проход: PASS_WITH_RISKS, XYZ/frame/margins/UNKNOWN сохранены; reference-геометрия не заимствуется из предыдущего кадра. Во время ожидания явно виден номер оставленного кадра.
