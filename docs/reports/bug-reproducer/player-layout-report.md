## Root cause

review-tools был раскрываемым элементом внутри header во flex-потоке страницы.

## Approved fix

Панель заменена на постоянный aside в #workspace; body использует grid, #scene занимает minmax(0, 1fr).

**Why this is causal:** aside вынесен из header, поэтому раскрытие больше невозможно и не может менять высоту header.
