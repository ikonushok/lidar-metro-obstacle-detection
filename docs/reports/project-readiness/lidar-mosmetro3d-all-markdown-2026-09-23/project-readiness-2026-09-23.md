**Все MD нельзя признать актуальными.** Часть противоречит реализации; часть корректна только как датированная история, требования или будущий дизайн. Реализованы direct C++ и headless ROS2 с общей моделью, но общая методология и план ещё описывают предыдущие этапы. У проекта есть исследовательская реализация; независимая оценка и воспроизводимая сдача остаются отдельными незавершёнными работами.

## Что сделано сверх общей сводки плана

Общее C++ ядро/CurveRailAxis/tangent уже частично учтены в work_plan — их нельзя целиком назвать работой вне плана. Недостаточно отражены: обученная model_v1 и её интеграция в оба адаптера, прямой транспорт плеера, frozen-tree inference, полная семиисточниковая development-оценка, arc_clamped, synthetic generator и исследования движения. Для многих есть собственные stage task specs: это расширения относительно общей сводки, **не доказательство несанкционированных действий**.

Legacy JS temporal/noise policy тоже реализовывалась, но не должна попадать в перечень активных свойств model_v1. Сейчас модель является бинарным фильтром CORE-компонентов, а не классификатором семантических классов объектов.

## Проверки, ограничения, следующий шаг

Полный файловый охват и команды — [index](index.md), [inventory](markdown-inventory.md). Уровень L0 для соответствия документации; L1 только для manifest и 11 существующих tests. Следующий минимальный шаг — корректировка главного README/методологии/плана/модели по D0–D2; внешний факт перепроверять только при переносе его в новое обязательство.
