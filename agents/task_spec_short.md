# Краткая спецификация задачи

Заполнять перед нетривиальными изменениями, многофайловой работой, калибровкой, validation claim или подготовкой demo/release.

Это шаблон: сохранять заполненный экземпляр в `artefacts/task_specs/<purpose>.md`, не перезаписывать данный файл. При продолжении той же задачи обновлять её экземпляр; прежние экземпляры в других путях переносить не требуется.

Отчёт о выполнении этапа хранить отдельно от task spec: в `artefacts/task_specs/<purpose>.md`. Отчёты, не относящиеся к этапу плана, хранить в `docs/reports/<category>/`; корневой `reports/` не использовать.
